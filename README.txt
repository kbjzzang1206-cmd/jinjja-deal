진짜딜 정적 웹사이트 시제품
=============================

포함 파일
- index.html       메인 화면 및 검색/분류 가능한 가상 상품 비교 카드
- guide.html       구매 가이드 콘텐츠
- about.html       서비스 소개 및 현재 기능 한계
- privacy.html     현재 시제품 기준 개인정보 처리방침 초안
- contact.html     실제 문의 수단 추가 안내
- style.css        반응형 디자인
- app.js           브라우저 안에서 동작하는 데모 검색/분류 기능

중요
1. 가격과 상품명은 가상 예시입니다. 실시간 판매가가 아닙니다.
2. 실시간 가격 추적, 자동 알림, 로그인, 제휴 링크는 구현되어 있지 않습니다.
3. 이 파일을 배포했다고 쿠팡 파트너스 가입 또는 최종 승인이 보장되지는 않습니다.
4. 공개 배포 전에는 연락 수단, 운영 주체, 개인정보 처리 내용, 콘텐츠를 실제 운영 상황에 맞게 확인/수정하세요.
5. 쿠팡 파트너스 활동을 시작하면 공식 정책에 따라 링크가 게시될 모든 활동 채널을 등록하고, 가입 후 요구되는 스크린샷을 제출하세요.
6. 쿠팡 상품 가격을 자동 수집하기 전에 공식적으로 허용된 데이터 접근 방법과 최신 운영정책을 확인하세요.

무료 배포 방향
- GitHub 저장소를 만들고 이 폴더 안의 파일을 업로드합니다.
- GitHub 저장소 Settings > Pages에서 배포를 설정합니다.
- 공개된 HTTPS 주소가 열리는지 PC와 휴대폰에서 확인합니다.
- 배포 방법과 화면은 서비스 변경에 따라 달라질 수 있으므로 GitHub Pages의 최신 안내를 확인하세요.

다음 개발 단계
1. 가상 가격 카드를 실제 가격으로 오해하지 않도록 유지
2. 허용된 가격 데이터 공급 방식 확인
3. 데이터 저장소와 가격 기록 구조 설계
4. 사용자별 목표가 저장 및 알림 기능 개발
5. 대체 상품 비교 기준(용도, 사양, 가격)을 명확히 정의
